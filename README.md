# Pemancingan Raja 🎣

Website resmi tempat pemancingan dengan tagline **"Kurangi Pikiran, Banyakin Tarikan!"**. Platform ini dirancang untuk memberikan informasi seputar pemancingan, fasilitas, lokasi, serta fitur login untuk pengunjung.

## 📌 Fitur Utama

* **Halaman Utama**: Berisi sambutan, promosi, dan navigasi utama.
* **Galeri**: Menampilkan suasana dan fasilitas kolam pemancingan.
* **Lokasi**: Informasi titik lokasi pemancingan.
* **Sistem & Akun**: Fitur registrasi (Buat Akun) dan login (Masuk Akun) untuk pengunjung.

## 🛠️ Teknologi yang Digunakan

* **HTML5**
* **CSS3**
* **JavaScript**
